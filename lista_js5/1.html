O que é JavaScript?

Quem criou?

O criador do JavaScript é o programador e tecnólogo americano Brendan Eich

JavaScript foi criado para tornar as páginas web interativas, permitindo responder às ações dos usuários, validar formulários e atualizar conteúdos sem precisar recarregar a página inteira. No navegador, o JavaScript pode manipular elementos HTML e responder às interações do usuário. No servidor, por exemplo com Node.js, pode executar operações como acessar bancos de dados e processar requisições. O sandbox é um mecanismo de segurança que limita o acesso do código executado no navegador a recursos do computador e do sistema, ajudando a proteger o usuário. O document permite acessar e modificar o documento HTML; o console permite registrar mensagens para depuração; e o alert exibe uma caixa de diálogo com uma mensagem.
