# Lista de Exercícios - JavaScript

Arquivos das 14 questões da lista de PPI.

## Como abrir
Abra o arquivo `index.html` no navegador e escolha uma questão.

## Organização
- `1.html` até `14.html`: exercícios.
- `imgs/`: imagens usadas na questão 4.

## Observação sobre a questão 4
As imagens SVG incluídas são ilustrações simples para que o exercício funcione sem depender de imagens externas. Se preferir usar as imagens indicadas pelo professor, coloque-as na pasta `imgs` e ajuste os caminhos no arquivo `4.html`.

## Git
Depois de copiar a pasta para dentro do repositório de PPI, confira as alterações com:

```bash
git status
```

Faça um commit quando estiver tudo conferido.
