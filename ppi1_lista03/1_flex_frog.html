Flexbox Froggy

Acesse Flexbox Froggy

Nível 13

Código utilizado:

#pond {
    display: flex;
    flex-direction: row-reverse;
    justify-content: center;
    align-items: flex-end;
}

Explicação:

A propriedade display: flex ativa o Flexbox no elemento #pond, permitindo organizar os elementos de acordo com as regras do Flexbox.

A propriedade flex-direction: row-reverse organiza os elementos em uma linha, mas inverte a direção da ordem dos elementos.

A propriedade justify-content: center centraliza os elementos no eixo principal.

A propriedade align-items: flex-end posiciona os elementos no final do eixo transversal.

Nível 14

Código utilizado:

#pond {
    display: flex;
}

.yellow {
    order: 1;
}

Explicação:

A propriedade display: flex transforma o elemento #pond em um container Flexbox.

A propriedade order permite alterar a ordem visual dos elementos dentro de um container Flexbox.

Por padrão, os elementos possuem o valor order: 0. Ao utilizar order: 1 no elemento .yellow, o sapo amarelo é colocado depois dos elementos que permanecem com o valor padrão.
