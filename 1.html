O que é JavaScript?

JavaScript é uma linguagem de programação criada para deixar as páginas da internet interativas. No navegador, ela pode alterar elementos HTML, responder a cliques e atualizar informações na própria página. Também pode ser executada no servidor, por exemplo com Node.js, para trabalhar com dados e atender solicitações. No navegador, o código normalmente funciona em um ambiente chamado sandbox, que limita o acesso direto ao computador do usuário por segurança. Alguns objetos globais são document, usado para acessar o HTML; console, usado para registrar mensagens; e alert, usado para mostrar avisos.
