Nível 18

Este nivel pedia que alterace a ordem onde o veneno esticesse nas ervas daninhas e as cenouras sejam regadas.

O que foi aprendido ?

No nível 18 do Grid Garden, foi utilizada a propriedade order do CSS Grid.

Essa propriedade permite alterar a ordem em que os elementos aparecem dentro do Grid.

Solução do nível

#poison {
    order: 1;
}

Explicação

Por padrão, os elementos possuem o valor order: 0.

Ao colocar order: 1 no elemento #poison, ele passa a ser organizado depois dos elementos que possuem o valor padrão.
